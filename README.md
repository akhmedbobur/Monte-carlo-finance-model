# Monte-carlo-finance-model
Monte Carlo model for stocks that forecasts and shows 10.000+ different variations of the same stock future
How to use it?
Open file in your pc and then open terminal in it
Afterwards tipe this command to get alll nedded info (you can change stocks if you want to)
pip install numpy pandas matplotlib yfinance
python monte_carlo_var.py --tickers AAPL JPM XOM JNJ --years 3
And then you will get results in your folder
